# KOAP VC Core (Standalone Repository)

Fresh standalone Telegram voice chat audio/video streaming bot repository built from scratch.

## Quick Start
1. Copy `.env.example` to `.env` and fill in your Telegram API credentials, bot token, and userbot session string.
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the worker:
   ```bash
   python -m koap_vc
   ```
